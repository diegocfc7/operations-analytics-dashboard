# Operations Analytics Dashboard

Interactive dashboard for **operational performance, analytics and decision support**, built with HTML, CSS, JavaScript and Chart.js.

> 🇧🇷 Projeto demonstrativo de inteligência operacional com dados 100% sintéticos.  
> 🇺🇸 Demonstration project for operational intelligence using 100% synthetic data.

## 🚀 Live Demo

👉 **[Open the Operations Analytics Dashboard](https://diegocfc7.github.io/operations-analytics-dashboard/)**

---

## 🎯 Project Purpose

Operational environments generate large volumes of data, but data alone does not improve performance.

This project demonstrates how operational information can be transformed into:

- performance indicators;
- interactive analytics;
- operational diagnostics;
- automated insights;
- decision-support information.

The core concept is:

```text
Operational Data
      ↓
   Analysis
      ↓
   Diagnosis
      ↓
 Decision Support
      ↓
Better Operations
```

---

## 📊 Dashboard Features

### Executive KPIs

The dashboard dynamically calculates:

- **Total Operations**
- **Conversion Rate**
- **SLA Compliance**
- **Average Response Time**

KPIs are recalculated automatically according to the selected filters.

### Interactive Filters

Users can analyze performance by:

- Period
- Region
- Team
- Service Type

All dashboard components respond dynamically to the selected filters.

### Operational Performance

Interactive visualization combining:

- Daily operational volume
- Conversion rate
- Performance trends

### Non-Conversion Analysis

Breakdown of the main non-conversion drivers:

- Network Availability
- Customer Decision
- Operational Failure
- Geographic Restriction
- System Issues
- Other

### Automated Operational Insights

The application interprets the filtered dataset and generates observations about:

- conversion performance;
- SLA compliance;
- average response time;
- main non-conversion driver.

---

## 🧠 Analytics Approach

Rather than displaying static indicators, the application follows an analytical workflow:

```text
Synthetic Operations
        ↓
      Filters
        ↓
 Filtered Dataset
        ↓
 ┌──────┼─────────┐
 ↓      ↓         ↓
KPIs   Charts   Insights
 ↓      ↓         ↓
 └──────┴─────────┘
        ↓
 Operational Decision Support
```

This structure simulates how operational intelligence tools can transform raw events into management information.
